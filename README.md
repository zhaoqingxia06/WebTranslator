# 网页双语对照

Chrome 插件：在网页右侧显示翻译，支持双向滚动和选中文本联动高亮。

## 安装

1. 下载仓库（Code → Download ZIP）并解压。
2. 在 Chrome 打开 `chrome://extensions`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择仓库中的 `bilingual` 文件夹。
4. 刷新文章页面，点击插件图标打开侧栏。

## 当前状态

版本 0.5.4 为开发测试版，尚未完成真实浏览器端到端验收。复杂页面的内容提取、段落对齐、双向滚动和关闭还原需要进一步验证。词句高亮使用翻译片段和文本匹配，不保证对所有词句准确定位；尚未接入本地词级对齐模型。PDF、视频字幕和图片中的文字暂不支持。

插件调用 Google 翻译的非正式接口，网页文字会发送到该服务；服务可用性及语言覆盖可能变化。浏览器扩展需访问 HTTP/HTTPS 网页以读取待翻译内容。
